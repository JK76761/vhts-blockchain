# vhts-blockchain

Hardhat Solidity project for the IFB452 blockchain assignment.

## Tech Stack

- Solidity `^0.8.20`
- Hardhat
- JavaScript configuration and deployment scripts

## Project Structure

```text
contracts/   Solidity smart contracts
scripts/     JavaScript deployment and utility scripts
test/        Hardhat tests
```

## Commands

```shell
npm install
npm run compile
npm test
```

Contracts and deployment scripts will be added in later tasks.
